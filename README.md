## About the Project
This repository was created as part of our assignment to practice working with GitHub repositories, team collaboration, and access permissions.

## Team Members and Roles

- **Aljawharah Alrasheed** — Admin
- **Leen** — Write Access

## Access Permissions
- **Admin:** Has full control over the repository, including managing settings and members.
- **Write:** Can contribute to the repository by adding and editing files.
- **Read:** Can view and download repository files.

## Purpose
The purpose of this assignment is to learn how to create and manage a GitHub repository, assign different permission levels, and collaborate as a team.
